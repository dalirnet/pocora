# Pocora Parent

## Short description

```text
Set your child's internet
```

## Description

```text
Pocora helps families keep their children's internet to the right amount and the right time; parents decide when, how much and with which apps their child goes online. Pocora is about conversation, not control; every report is a reason to talk with your child.

Pocora Parent goes on the parent's phone.
Install Pocora Child on each child's phone.

Features

• Ready presets for the school year, exams, Ramadan and summer.
• Set internet time, allowed apps and data for each child.
• One tap: 30 more minutes, more data, stop or allow internet.
• Usage of each app over the last 7 days.
• Alerts when Pocora is turned off or a watched app is opened.
• Many children and two parents in one family.
• A 4-digit PIN to open the app.

Privacy

• No server, no account; the two phones talk only over the home Wi-Fi.
• Messages, photos and websites are never seen.

Made for children aged 8 to 16. Free and open source.
```
