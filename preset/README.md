# Presets

Ready-made choices the parent picks from, so nothing has to be built from an empty screen.

> Overview: [`README.md`](../README.md)

| Folder | Answers | Presets |
| --- | --- | --- |
| [`schedule/`](./schedule/README.md) | When is the internet Allowed? | 11 weeks: school, holidays, simple rules |
| [`apps/`](./apps/README.md) | Which apps have internet in an Allowed mark? | 8 lists: by age and by purpose |
| [`quota/`](./quota/README.md) | How much data per mark? | 4 levels: Light, Medium, High, No limit |
| [`holidays/`](./holidays/README.md) | Which days have no school? | Iran's official holidays, 1405 to 1409 |

A child has one schedule preset, one apps preset and one quota preset. The schedule and the quota together give the most the child can use in a month.
