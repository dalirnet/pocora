# Everything

For families who limit by time and quota, not by app.

- **Age:** Any
- **Groups with internet:** 13 of 13
- **Goes well with:** **Watch only**, **Nights off**

## Apps

```
[x] System       Phone, messages, keyboard, updates
[x] School       Shad, live class apps
[x] Learning     Schoolwork, languages, books, Quran
[x] Kids         Digitoon, Aparat Kids, stories
[x] Messaging    WhatsApp, Eitaa, Bale, iGap
[x] Daily tools  Maps, taxi, calendar, weather
[x] Music        Music, radio, podcasts
[x] Video        Telewebion, Aparat, Filimo
[x] Games        Every game
[x] Stores       Bazaar, Myket, Google Play
[x] Browser      Chrome, Firefox and others
[x] Social       Rubika, Chatzy, Wisgoon
[x] Other        Shopping, banking, anything unlisted
```

`[x]` has internet in an Allowed mark. `[ ]` does not. The apps in each group are in [`groups/`](./groups/README.md).

## Why this list

- Every app has internet in an Allowed mark.
- VPN apps are the one exception in every preset. Android refuses them while Pocora is on.

## Adjust

- Mark single apps as always out instead of changing the whole list.
